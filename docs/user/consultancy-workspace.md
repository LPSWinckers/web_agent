# Consultancy workspace

Open **Workspace** from the customer sidebar. Add a customer, then create a project with a name and a folder on the connected environment. The project page shows files in that folder and keeps its AI conversations together.

Open a file from **Project files** to read it. Workbooks fill the screen; choose **Ask about file** to open a side chat for row counts, missing values, duplicates, and numeric summaries of the selected sheet. PDFs, Word documents, images, and text files open on the project page. Use **Refresh** when files in the folder change. Choose **Ask AI about this project** or **New chat** for broader questions about the project files.

Files added through the earlier upload flow remain under **Previously added files**. Their originals are stored in the browser where they were added.
