# Presentations

In a project's **Files** panel, choose **Create presentation**. The consultancy project page also has **New presentation** above Project files. Add cover, section, key points, two-column, and chart slides. Save the deck to place both an editable `.t3deck.json` source and a `.pptx` in the project's `powerpoints` folder. Open either file from **Files** or Project files to revise the slides. Project files open in full-screen tabs; use the project tab to return to the overview. Tabs belong to the selected project. **Save and download** also puts the PowerPoint file on your device.

For a chart, choose a `.xlsx`, `.csv`, or `.tsv` file. The first worksheet uses column A for labels and columns B through E for numeric series. Choose a bar, line, area, pie, doughnut, or scatter chart. Scatter charts use the first numeric series for X and the second for Y. Set the chart unit (such as `%`) and add a source citation so readers can trace the figures. The chart remains editable in PowerPoint.

Ask the agent to show a chart in chat to see it directly in the web conversation. The agent uses the same chart data and Berenschot style for chat and presentation slides.

In a consultancy project, start a presentation chat in the sidebar. You can ask questions without changing the deck. To request an edit to one part of a slide, use the selection button and click its title, text, or chart before describing the change. The chat receives the open deck path and selected slide. Valid edits to the deck source appear in the preview and refresh the `.pptx` export.

To use approved photography, connect the library in **Settings → Company → SharePoint image bank**. Enter its sharing link and the public-client application ID, sign in with Microsoft, and map the columns that contain image themes, type, workfields, keywords, and usage restrictions. If restriction tags share the keyword column, map that column to both. Then ask the presentation agent to find suitable images. It searches the mapped metadata and imports selected images into the project. Images marked with usage restrictions need your explicit authorization before they can be used.

Every deck uses the shared **Berenschot 2026** slide style. Existing editable decks use that style when opened and exported. In **Settings → Company**, you can see the five slide layouts and one reusable example of each chart type. The presentation chat receives the same slide and chart rules when you ask it to create or change a deck.
